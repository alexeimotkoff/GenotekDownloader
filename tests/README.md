# Тестовые данные

Карточки людей, имена, даты, связи и значения «Тестовая группа А/Б» вымышлены. Идентификаторы вроде `synthetic-tree` и `father` служат только тестам. Демонстрация использует те же вымышленные карточки.

Географические названия выбраны независимо от пользовательского древа. Открытые примеры адресов:

- **300000, Тула, Кремль** — [контакты Тульского музейного объединения](https://museum-tula.ru/contacts/).
- **Ярославль, Богоявленская пл., 25** — [страница Ярославского музея-заповедника](https://yarkremlin.ru/events/permanent/slovo-o-polku-igoreve/).

Координаты в тестах заданы искусственно для проверки точности, диапазонов и полушарий. Они не обозначают точное положение перечисленных музеев. Пример с семью десятичными знаками: `54.1234567, 37.7654321`.

Названия «Примерный», «Вымышленное», «Тестовое место» и подобные, сочетания одноимённых административных уровней, неполные адреса и числовые счётчики — искусственные граничные случаи. Общие названия регионов и стран нужны для проверки адресного формата.

Тесты и демонстрация работают без запросов к источникам адресов и геосервисам. Реальные выгрузки и данные аккаунтов в фикстуры не добавляются.
